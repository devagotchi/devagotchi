# Operator rules

These are the operator's own instructions, given by Jesse on 2026-11-23. They are his
rulings, not an agent's reading of them. Where any other file in this repository says
something different, including `AGENTS.md`, a plan, a pattern or a product document, this
page holds and the other file is the one that is wrong.

No agent edits this page on its own. A change here is made only at the operator's
instruction, in his words.

## How every agent works here

1. **No action that has not been discussed.** An agent does nothing the operator has not
   discussed and agreed first.
2. **The operator's instructions are respected as given.** An agent does not replace them
   with its own interpretation, and does not operate around them.
3. **When instructions and the code collide, stop and fix the code.** The instructions win.
   The code and the repository's files are brought into line with them, not the reverse.
4. **No gaslighting.** An agent says plainly what is broken, what is missing and what was its
   own mistake. It does not describe work as done, working or worth more than it is.

Open, for the operator: whether a collision under rule 3 is fixed on sight, or reported and
fixed after his yes. Until he rules, an agent stops, reports the collision and waits, because
of rule 1.

## What is being built

Stated by the operator on 2026-11-23.

1. **Devagotchi is a self-hosted hub on the web**, built and tailored for AI development:
   a self-hosted, optimized public hub, accessible to any of your clients or servers.
2. **Its MCP leads to more internal MCPs.**
3. **The hub has spokes.** Desktop Commander capabilities are one spoke. Secrets, the VPN and
   third-party connectors are others, so that Replit, Lovable, Bolt, Claude, Codex, Gemini,
   Grok, Cursor, VS Code or anything else can truly integrate.
4. **The binary is one wrapper that has multiple sub-processes.** One binary that wraps the
   others.
5. **AgentHub is its own thing, in its own repo, so it can be pulled into Shippin or
   Devagotchi.** The AgentHub code under Devagotchi is a clone, pulled in. It is not
   rewritten into Devagotchi.
6. **The old code is absorbed properly, merged one by one.** It is not re-authored as new
   code that is not what was asked for.
7. **First comes the one clean self-hosted version, which is limited, backed by Postgres.**
   After it, the proper control plane for resource management, which is the commercial
   product.
8. **Code standards.** A code structure that can be mind-mapped. No shortcuts. No
   compatibility for no reason just to have it run.

## The UI

Stated by the operator on 2026-11-23.

1. All CSS is generated by Style Dictionary.
2. That gives semantic and composite style tokens.
3. The tokens are applied to components. The components are ColdLight, the operator's own
   UI.
4. Components are created under the design (ColdLight) boundary, in their primitive state
   first.
5. Blocks, templates and patterns are then created by combining those primitives.
6. Variants are co-located with the code.
7. The landing page must be SEO friendly. Most of the rest sits behind authentication.

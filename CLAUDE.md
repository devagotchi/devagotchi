# Claude discovery adapter

@AGENTS.md

The imported root instructions are canonical. This file adds only Claude-specific
discovery. Repository capture hooks are in `.claude/settings.json`; they require the
`devagotchi` binary on PATH and explicit local capture consent. They do not replace
board lifecycle hooks, and do not imply that Claude Desktop or hosted chat supports
the Claude Code lifecycle. See [.ai/docs/adapters.md](.ai/docs/adapters.md).

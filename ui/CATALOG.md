# The ColdLight catalog

Generated by `npm run catalog` from the token sources and each component's `<Name>.variants.ts`. Do not edit.
The same data, for tools and AIs, is in [catalog.json](catalog.json).

## How to build a screen

- Build a screen from ColdLight components; reach for a lower level only when no higher one fits.
- Style with tokens only: `var(--cl-…)` from the list below. stylelint refuses a literal colour, size, weight or font, and names the closest token.
- Give every component its words through props or snippets; no text is written inside a component.
- A level imports only from the levels below it: primitives, then blocks, templates and patterns.
- Each component folder holds <Name>.svelte, <Name>.variants.ts, <Name>.stories.svelte and <Name>.test.ts.

## Components

### Primitives

#### Badge

A short label for the state of something: online, approved, waiting, failed. [src/coldlight/primitives/Badge/](src/coldlight/primitives/Badge/)

**Use:** Beside a name or in a table cell, to say in a word or two what state a thing is in, as the API reports it.

**Instead:** Explaining what happened and what to do next: use Notice. Anything that can be pressed: use Button.

```svelte
<Badge tone="success">Online</Badge>
```

**tone** (default `neutral`): What kind of state it names. The words say it too; colour is never the only sign.

- `neutral`: A plain fact with no judgement: a channel, a kind, a count.
- `accent`: Selected, current or yours: the board you are on, your own agent.
- `success`: Done, online, allowed.
- `warning`: Needs attention but nothing failed: offline, expiring.
- `pending`: Waiting on someone or something: an approval, a running job.
- `danger`: Failed, refused or revoked.

| Prop | Type | |
|---|---|---|
| `children` (required) | `Snippet` | The state, in a word or two (Online, Waiting for approval). |
| `tone` | `'neutral' \| 'accent' \| 'success' \| 'warning' \| 'pending' \| 'danger'` | See the tone variants. |

**Accessibility:** Plain inline text, read in its place: it has no role and takes no focus. Its words carry the meaning, so a screen reader and a colour-blind reader get the same state.

#### Button

A control that does one thing when pressed. [src/coldlight/primitives/Button/](src/coldlight/primitives/Button/)

**Use:** Any action: save, approve, cancel, open a dialog. A screen has at most one solid accent button, its main action.

**Instead:** Going to another page: use a link. Choosing one of several options: use Tabs or Select.

```svelte
<Button tone="accent" emphasis="solid" onclick={save}>Save</Button>
```

**tone** (default `neutral`): What kind of action it is.

- `neutral`: An ordinary action.
- `accent`: The main action of the screen.
- `danger`: An action that destroys or refuses something: delete, revoke, deny.

**emphasis** (default `outline`): How loudly it asks to be pressed.

- `solid`: Filled with its tone: the one action the screen is for.
- `outline`: Edged: a normal action beside others.
- `quiet`: Text only: a minor or repeated action, such as one in every row of a table.

| Prop | Type | |
|---|---|---|
| `children` (required) | `Snippet` | The label: a verb for what it does (Save, Approve). |
| `tone` | `'neutral' \| 'accent' \| 'danger'` | See the tone variants. |
| `emphasis` | `'solid' \| 'outline' \| 'quiet'` | See the emphasis variants. |
| `busy` | `boolean` | The action is running: the button is disabled and says so to screen readers. |
| `disabled` | `boolean` | The action cannot run now. Say why nearby. |
| `type` | `'button' \| 'submit' \| 'reset'` | Defaults to button; a form's own button is submit. |
| `onclick` | `(event: MouseEvent) => void` | What pressing it does. |

**Accessibility:** A native <button>: Enter and Space press it, and it is labelled by its text. When busy it carries aria-busy. It is at least 48 dp in both directions.

#### Card

A surface that groups one thing: its title, a line about it, its actions and its content. [src/coldlight/primitives/Card/](src/coldlight/primitives/Card/)

**Use:** One machine, one agent, one setting group, one dashboard figure: anything a screen shows several of side by side or one after another.

**Instead:** A row in a long list: use List or Table. A message about a failure: use Notice. Content that must be answered before going on: use Dialog.

```svelte
<Card title="texas" description="Windows 11, online">{#snippet actions()}<Button>Open</Button>{/snippet}…</Card>
```

**emphasis** (default `flat`): How far it stands off the canvas.

- `flat`: Edged and level with the page: the usual card, many to a screen.
- `raised`: Lifted with a shadow: the one card a screen is about, or one that can be picked up.

| Prop | Type | |
|---|---|---|
| `title` | `string` | What the card is about, as a heading. |
| `headingLevel` | `2 \| 3 \| 4 \| 5 \| 6` | The title's heading level, so it fits the page's outline. Defaults to 2. |
| `description` | `string` | One line about it, under the title. |
| `actions` | `Snippet` | Buttons for the whole card: beside the title on a wide card, under it on a narrow one. |
| `children` | `Snippet` | The content. |
| `emphasis` | `'flat' \| 'raised'` | See the emphasis variants. |

**Accessibility:** A plain group: the title is a real heading at the level given, so screen reader users can jump between cards by heading. Actions come after the title in reading and Tab order.

#### Code

Code, a path, a command or an ID, set in the code face and kept exactly as written. [src/coldlight/primitives/Code/](src/coldlight/primitives/Code/)

**Use:** Anything a person types, pastes or reads character by character: a command to run, a config line, a file path, a token's prefix, a machine ID.

**Instead:** Changes between two versions: use Diff. Ordinary emphasis in a sentence: use the text's own weight.

```svelte
<Code code="devagotchi hub serve" language="bash" copyLabel={t.copy} copiedLabel={t.copied} />
```

**display** (default `block`): Where it sits.

- `block`: Its own block: a command or a snippet of several lines. It scrolls sideways inside itself rather than wrapping.
- `inline`: Inside a sentence: a path, a flag or an ID. It wraps anywhere rather than widening the page.

| Prop | Type | |
|---|---|---|
| `code` (required) | `string` | The exact text. |
| `language` | `string` | What it is written in (bash, toml). A block shows it as a label; both carry it as data-language. There is no highlighting. |
| `copyLabel` | `string` | The label of a copy button (Copy). Without it there is no button. |
| `copiedLabel` | `string` | What is announced, and shown, once the text is on the clipboard (Copied). |
| `copyFailedLabel` | `string` | What is announced, and shown, when the clipboard refuses and the text is selected to copy by hand (Copy it by hand; the text is selected). |
| `display` | `'block' \| 'inline'` | See the display variants. |

**Accessibility:** Inline it is a <code>; as a block it is <pre><code>, focusable so a keyboard can scroll a long line. The copy button is a Button, at least 48 dp. A copy is announced through a polite live region (role=status). If the clipboard refuses, the text is selected instead, ready to copy by hand.

#### Dialog

A modal window over the page that holds one task or one question until it is answered or closed. [src/coldlight/primitives/Dialog/](src/coldlight/primitives/Dialog/)

**Use:** A confirmation before something hard to undo, a short form that belongs to the current screen, or a choice the screen cannot go on without.

**Instead:** Telling someone something happened: use Notice. Long or multi-step work: give it its own page.

```svelte
<Dialog bind:open title={t.revokeTitle} closeLabel={t.close} tone="danger">{t.revokeBody}</Dialog>
```

**tone** (default `neutral`): What kind of question it asks.

- `neutral`: An ordinary task or question.
- `danger`: A confirmation before something destructive: delete, revoke, deny. Its top edge and title carry the danger colour.

| Prop | Type | |
|---|---|---|
| `open` | `boolean` | Whether it is showing. Bindable: closing it by Escape or the close button sets it to false. |
| `title` (required) | `string` | The heading, and the dialog's accessible name. |
| `description` | `string` | One sentence under the title that says what is being asked; it becomes the accessible description. |
| `children` (required) | `Snippet` | The body: the form or the details. |
| `actions` | `Snippet` | The footer buttons. The main action goes last. |
| `closeLabel` (required) | `string` | The accessible name of the close button (Close). |
| `tone` | `'neutral' \| 'danger'` | See the tone variants. |
| `onclose` | `() => void` | Called when the person closes it by Escape or the close button. |

**Accessibility:** A native <dialog> opened with showModal(): it sits in the top layer, keeps focus inside, and Escape closes it. It is named by its title (aria-labelledby) and described by its description (aria-describedby). The close button is at least 48 dp.

#### Diff

Two versions of a text, line by line: what a change keeps, removes (red) and adds (green). [src/coldlight/primitives/Diff/](src/coldlight/primitives/Diff/)

**Use:** Previewing a change before anything is written: a file edit, a setting, an import. The conflict pattern shows one for each choice.

**Instead:** Showing one version: use Code.

```svelte
<Diff label="config.toml" before={current} after={incoming} addedLabel="Added" removedLabel="Removed" />
```

**wrap** (default `scroll`): What a line longer than the box does.

- `scroll`: The diff scrolls sideways inside itself; lines keep their shape. For code.
- `wrap`: Long lines wrap. For prose and settings.

| Prop | Type | |
|---|---|---|
| `before` (required) | `string` | The version now in place. |
| `after` (required) | `string` | The version the change would write. |
| `label` (required) | `string` | What is being compared, for screen readers (the file or setting name). |
| `addedLabel` (required) | `string` | The word read before an added line (Added). |
| `removedLabel` (required) | `string` | The word read before a removed line (Removed). |
| `unchanged` | `Snippet` | Shown when the two versions are the same. |
| `wrap` | `'scroll' \| 'wrap'` | See the wrap variants. |

**Accessibility:** A list of lines labelled by `label`. Each added or removed line starts with its word, read aloud and hidden on screen; the + and − markers and the colours repeat it for sighted readers, so colour is never the only signal. A scrolling diff can be reached and scrolled with the keyboard.

#### Field

A labelled text input, or a labelled text area when it takes more than one line. [src/coldlight/primitives/Field/](src/coldlight/primitives/Field/)

**Use:** Any free text a person types: a name, an email, a URL, a search, a number, a note. Give it a hint when the format is not obvious, and an error when the value is refused.

**Instead:** Choosing one of a known set of values: use Select. A yes or no: use a checkbox.

```svelte
<Field label="Email" type="email" autocomplete="email" hint="We send the sign-in link here." bind:value={email} />
```

**width** (default `fill`): How much of the line the control takes.

- `fill`: The whole width of its container: the usual field in a form.
- `fit`: Only as wide as its content needs: a short value such as a port or a count, beside other controls.

| Prop | Type | |
|---|---|---|
| `label` (required) | `string` | What the field is for, as a noun (Email, Machine name). Mark a required field in the label's words. |
| `value` | `string \| number \| null` | The text in the field. Bind it: bind:value. A number field binds a number. |
| `hint` | `string` | How to fill it in: the format, a limit, an example. Read out after the label. |
| `error` | `string` | Why the value is refused and how to fix it, from the API's refusal. When set, the field is marked invalid and the message is read out. |
| `multiline` | `boolean` | A text area for more than one line, instead of a single-line input. |
| `type` | `'text' \| 'email' \| 'password' \| 'url' \| 'search' \| 'number'` | The kind of text, which picks the phone keyboard. Ignored when multiline. |
| `width` | `'fill' \| 'fit'` | See the width variants. |
| `required` | `boolean` | The form cannot be sent without it. |
| `disabled` | `boolean` | It cannot be changed now. Say why in the hint. |
| `name` | `string` | The form field's name. |
| `autocomplete` | `string` | What the browser may fill in: email, username, current-password, off. |

**Accessibility:** A native <input> or <textarea> with a <label> bound to it, so the label is its accessible name and clicking the label focuses it. The hint and the error are linked with aria-describedby; an error also sets aria-invalid. The control is at least 48 dp tall.

#### List

A vertical list of items drawn from data, one row each, with dividers, and an empty state when there are none. [src/coldlight/primitives/List/](src/coldlight/primitives/List/)

**Use:** Machines, agents, notes, recent activity: things that read one per line and are each the same shape. Give it an empty snippet that says what would be here and how to add one (U7).

**Instead:** Rows compared column by column: use Table. A few unrelated things: use Cards.

```svelte
<List items={machines} key={(m) => m.id} label="Machines">{#snippet item(m)}{m.name}{/snippet}</List>
```

**density** (default `comfortable`): How much room each row has.

- `comfortable`: Room to read and to touch: the usual list.
- `compact`: Tight rows for long lists of short items, such as an activity feed.

| Prop | Type | |
|---|---|---|
| `items` (required) | `T[]` | The items, in the order the API gave them. |
| `item` (required) | `Snippet<[T]>` | How one item is drawn. |
| `key` (required) | `(item: T) => string` | Each item's stable identity, usually its id, so rows keep their state when the list changes. |
| `label` (required) | `string` | What the list is (Machines), read out as the list's name. |
| `empty` | `Snippet` | Shown in place of the list when there are no items: what would be here and how to add one. |
| `density` | `'comfortable' \| 'compact'` | See the density variants. |

**Accessibility:** A native <ul> named by aria-label, so a screen reader says what the list is and how many items it has. Each item is an <li> in data order. When empty, the empty snippet is shown instead and no empty list is announced.

#### Notice

An inline message that says what happened, why, and what to do next (U9). [src/coldlight/primitives/Notice/](src/coldlight/primitives/Notice/)

**Use:** A refusal or failure from the API, shown from its {code, message, next}; a warning before an action; the result of one. When the API offers a fix, put it in next as a Button.

**Instead:** A one-word state: use Badge. A question that must be answered before going on: use Dialog.

```svelte
<Notice tone="danger" title="Deploy refused" live>Port 80 needs administrator rights.{#snippet next()}<Button onclick={usePort8080}>Use port 8080</Button>{/snippet}</Notice>
```

**tone** (default `info`): What kind of message it is.

- `info`: Something worth knowing; nothing is wrong.
- `success`: What was asked for was done.
- `warning`: Nothing failed yet, but something needs attention.
- `danger`: Something failed or was refused.

| Prop | Type | |
|---|---|---|
| `title` (required) | `string` | What happened, in one short line (Deploy refused). |
| `children` (required) | `Snippet` | Why it happened: the API's message, as plain text in full sentences. |
| `next` | `Snippet` | What to do next: the API's next, usually as a Button that does it. |
| `tone` | `'info' \| 'success' \| 'warning' \| 'danger'` | See the tone variants. |
| `live` | `boolean` | It appeared because of something the person just did, so a screen reader announces it: as an alert for warning and danger, politely for info and success. Leave it off for a notice that is part of the page from the start. |

**Accessibility:** Static by default: its text is read in its place. With live, a warning or danger notice has role=alert and is announced at once; an info or success notice has role=status and is announced when the reader is idle. Its title says what happened in words, so colour is never the only sign. Any control in next is reached by Tab in reading order.

#### Select

A labelled choice of one value from a known list, on the platform's own picker. [src/coldlight/primitives/Select/](src/coldlight/primitives/Select/)

**Use:** Choosing one of a handful or more of options that come from the API's configuration: a region, a role, a channel.

**Instead:** Two to four options that should all be visible: use radio buttons or Tabs. Free text: use Field.

```svelte
<Select label="Region" options={regions} bind:value={region} />
```

**width** (default `fill`): How much of the line the control takes.

- `fill`: The whole width of its container: the usual select in a form.
- `fit`: Only as wide as its longest option: a filter beside other controls.

| Prop | Type | |
|---|---|---|
| `label` (required) | `string` | What is being chosen, as a noun (Region, Role). |
| `options` (required) | `Array<{ value: string; label: string; disabled?: boolean }>` | The choices, in order, from the API's configuration. A disabled option is shown but cannot be chosen. |
| `value` | `string` | The chosen option's value. Bind it: bind:value. |
| `hint` | `string` | What the choice changes. Read out after the label. |
| `error` | `string` | Why the choice is refused and what to choose instead. When set, the select is marked invalid and the message is read out. |
| `width` | `'fill' \| 'fit'` | See the width variants. |
| `required` | `boolean` | The form cannot be sent without a choice. |
| `disabled` | `boolean` | It cannot be changed now. Say why in the hint. |
| `name` | `string` | The form field's name. |

**Accessibility:** A native <select> with a <label> bound to it, so the label is its accessible name and the platform's picker, keyboard and screen reader handling all apply. The hint and the error are linked with aria-describedby; an error also sets aria-invalid. The control is at least 48 dp tall.

#### Table

A semantic data table: rows of the same kind of record, compared column by column. [src/coldlight/primitives/Table/](src/coldlight/primitives/Table/)

**Use:** Records a person scans and compares: machines, tokens, grants, audit lines. On a narrow screen it scrolls sideways inside itself.

**Instead:** A handful of records each read on its own: use List or Card. Laying out a page: use grid, never a table.

```svelte
<Table caption={t.machines} {columns} rows={machines} rowKey={(m) => m.id}>{#snippet cell(m, key)}{m[key]}{/snippet}</Table>
```

**density** (default `comfortable`): How much room each row has.

- `comfortable`: Room to read: the default for most tables.
- `compact`: More rows on the screen: long logs and audit trails that are scanned rather than read.

| Prop | Type | |
|---|---|---|
| `caption` (required) | `string` | What the table holds. It names the table and its scrolling region. |
| `captionHidden` | `boolean` | Hide the caption visually when a heading beside the table already says the same; screen readers still hear it. |
| `columns` (required) | `Array<{ key: string; label: string; align?: 'start' \| 'end' }>` | The columns, in order. Numbers align to the end. |
| `rows` (required) | `T[]` | The records, one per row. |
| `rowKey` (required) | `(row: T) => string` | A stable, unique key for a record, such as its id. |
| `cell` (required) | `Snippet<[T, string]>` | Renders one cell, given the record and the column key. |
| `empty` | `Snippet` | The empty state, shown in one full-width row when there are no records: what is missing and what to do. |
| `density` | `'comfortable' \| 'compact'` | See the density variants. |

**Accessibility:** A native <table> with a <caption> and column headers (th scope=col). It sits in a region named by the caption that can be focused (tabindex=0), so a keyboard can scroll a table wider than the screen.

#### Tabs

A row of tabs that shows one of several panels of the same thing at a time. [src/coldlight/primitives/Tabs/](src/coldlight/primitives/Tabs/)

**Use:** Views of one object that a person moves between freely: a machine's overview, sessions and logs; the tabs of a settings domain.

**Instead:** Steps that must happen in order: use a form with sections. Going to another page: use links. Choosing a value for a form: use Select.

```svelte
<Tabs label={t.machineViews} {tabs} bind:selected>{#snippet panel(id)}<MachineView {id} />{/snippet}</Tabs>
```

| Prop | Type | |
|---|---|---|
| `label` (required) | `string` | The accessible name of the row of tabs (Machine views). |
| `tabs` (required) | `Array<{ id: string; label: string; disabled?: boolean }>` | The tabs, in order. A disabled tab is shown but cannot be chosen. |
| `selected` | `string` | The id of the chosen tab. Bindable. Without one, the first tab that is not disabled is chosen. |
| `panel` (required) | `Snippet<[string]>` | Renders the panel of the chosen tab, given its id. |

**Accessibility:** The WAI-ARIA tabs pattern with automatic activation: one tab is in the Tab order (roving tabindex); ArrowLeft and ArrowRight move to the previous and next tab and choose it, Home and End the first and last; disabled tabs are skipped. The chosen tab has aria-selected and aria-controls its panel; the panel is labelled by its tab. Each tab is at least 48 dp tall. The row scrolls sideways inside itself on a narrow screen.

### Patterns

#### ConflictResolver

The friendly popup for a change that meets a newer version: keep yours, take the incoming one, or merge both, with a red and green preview before anything is written. [src/coldlight/patterns/ConflictResolver/](src/coldlight/patterns/ConflictResolver/)

**Use:** Whenever the engine refuses a write because the target changed since it was read (changed_since_read), an import collides, or a setting is stale (ui.md U10). It is the only conflict UI: use it everywhere.

**Instead:** Asking someone to confirm an ordinary change with no newer version: use Dialog.

```svelte
<ConflictResolver bind:open title="config.toml changed while you were editing" name="config.toml" {existing} {incoming} {merged} {labels} onresolve={(choice, text) => api.files.write(path, text)} />
```

| Prop | Type | |
|---|---|---|
| `open` | `boolean` | Whether it is showing. Bindable. |
| `title` (required) | `string` | What happened, as a heading (This file changed while you were editing). |
| `description` | `string` | One sentence on why it matters and what the choice does. |
| `name` (required) | `string` | What is in conflict: the file path or setting, read out with the preview. |
| `existing` (required) | `string` | The version in place now, as the engine reported it. |
| `incoming` (required) | `string` | The version this change would write. |
| `merged` | `string` | Both merged, as the engine produced it. Without it, merging is not offered: the UI never merges by itself (U2). |
| `choice` | `'incoming' \| 'existing' \| 'merged'` | The selected choice. Bindable; defaults to incoming. |
| `labels` (required) | `ConflictLabels` | Every word it shows: the three choices and their hints, apply, cancel, close, the diff words, the no-change message and the counts. |
| `onresolve` (required) | `(choice, text) => void` | Called with the choice and the text to write when the person applies it. |
| `oncancel` | `() => void` | Called when the person closes it without choosing. |

**Accessibility:** A modal Dialog: focus stays inside and Escape cancels. The choices are a radio group with a legend, each choice reads its line counts, and the preview is a labelled Diff whose added and removed lines are read with their words.
